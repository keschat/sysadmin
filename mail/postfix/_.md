/etc/postfix/virtual, you must rebuild the indexed database file for Postfix to recognize the changes.

> Ref:
> https://help.univention.com/t/writing-entries-into-etc-postfix-virtual/6241
> https://www.postfix.org/VIRTUAL_README.html

- **Rebuild the database** by running this command in your terminal:
```bash
sudo postmap /etc/postfix/virtual
```
_(Note: Depending on your system configuration, this generates a virtual.db or similar indexed file.)_

- **Reload Postfix** to ensure it picks up the latest mapping state:
```bash
sudo systemctl reload postfix

#or

sudo postfix reload.
```
